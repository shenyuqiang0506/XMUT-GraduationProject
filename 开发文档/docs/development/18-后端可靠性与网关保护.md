# 后端可靠性与网关保护

日期：2026-10-13。范围：异常、身份故障转移、过期记录、设备匹配、网关保护。未增加联合申请、审批、取消业务。

## 异常与身份调用

业务拒绝保持原有状态；数据库连接和暂时性锁故障返回 503；错误 SQL、未知程序错误返回 500 `INTERNAL_ERROR`。内部异常记录 traceId 与堆栈，响应隐藏内部细节。认证过滤器和网关同样区分程序错误与依赖故障。

`IdentityServiceClient` 轮换首选实例，最多尝试两个不同实例。连接故障、超时、502/503/504 才切换，401/403/404、解析错误不重试；连接超时 500ms，读取超时 1s。仅调用只读接口，管理员响应改为 `UserSummary`，继续校验账号、状态、角色。

业务仍实时核对会话与当前角色，没有缓存允许访问的身份。数据库版本变化不会改变客户端旧 JWT，也不会自动使旧版本缓存失效。

## 过期记录与幂等

两库在 `business` profile 启用任务，默认启动一分钟后执行，每五分钟一轮，可通过 `RECORD_CLEANUP_INITIAL_DELAY_MS`、`RECORD_CLEANUP_DELAY_MS` 调整。只删除已过期的成功幂等记录，身份库额外删除到期的历史刷新摘要。每表每轮最多五批、每批 500 行，各批独立提交；失败记日志，下一轮继续。

有效刷新历史保留至会话到期，用于检测重放；不删除进行中记录、账号、会话、资源、占用、导入批次和审计。幂等请求在行锁内按数据库时间检查到期，过期成功记录重置后重新执行，结果与业务写入同事务提交。有效期内相同内容回放、不同内容返回 409；有效期外旧键可能重新执行，不能作为永久去重标识。账号唯一约束、导入批次状态等业务约束继续生效。

## 设备匹配

已通过原有可用性检查的设备按审批组、校区、类型建立索引，每请求构建一次，匹配时直接提取所需数量。保留 SQL 的 ID 顺序、跨组和跨校区隔离、设备不足拒绝等语义；组合匹配抽为独立方法。上限保持 2000 场地、5000 设备、10 类需求且总共最多 40 件，不调整覆盖判断或暂占逻辑。

## 网关配置

限流读取已验签 JWT 的用户 ID，忽略外部身份头。Redis Lua 原子检查总额度与专用额度，全部允许才计数，首次设置 TTL。键按 audience 与用户的联合摘要隔离，同用户不同会话共用额度。固定窗口允许相邻窗口突发，默认数值不代表生产容量压测。

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| `BUSINESS_RATE_GENERAL` | 240 | 每用户每窗口总请求数 |
| `BUSINESS_RATE_SEARCH` | 30 | 搜索额外额度 |
| `BUSINESS_RATE_IMPORT` | 20 | 目录、人员导入额外额度，包含批次读取 |
| `BUSINESS_RATE_WINDOW_MS` | 60000 | 窗口长度，可设 1 秒至 1 小时 |
| `GATEWAY_MAX_REQUEST_BYTES` | 3145728 | API 请求体上限，默认 3MiB |

超额返回 429 `BUSINESS_RATE_LIMITED`、秒级 `Retry-After` 与 traceId。Redis 故障返回 503，不降级放行，不改写下游错误。公开登录继续使用原有登录保护，退出撤销不受业务额度阻挡，下游仍实时认证。

请求体在认证前检查 Content-Length；分块传输逐块计数，超限释放缓冲并返回 413 `PAYLOAD_TOO_LARGE`，不缓存整个请求。业务服务仍限制单文件 2MB、multipart 请求 3MB。超限前转发的部分数据不代表写入成功，后端仍需完整解析和事务校验。前端当前为同源代理，没有额外开放 CORS。

启动器和 IDEA 配置向网关传递本环境 Redis 凭据，不传递数据库账号、签名私钥或管理员密码。

## 独立密码指纹密钥

身份服务必需配置 `AUTH_PASSWORD_FINGERPRINT_KEY_PATH`，指向 32 字节密钥文件，只交给身份服务。新环境由 `init-auth.py` 生成独立随机值；已有环境执行：

```sh
python3 deployment/scripts/migrate-fingerprint-key.py dev
python3 deployment/scripts/migrate-fingerprint-key.py prod
python3 deployment/scripts/prepare-idea.py
```

迁移保存当前派生值，兼容旧指纹，之后轮换 JWT 不再改变指纹。不修改账户密码或 JWT，不启动 prod，不覆盖不同的已有指纹密钥。本机两套配置已迁移，密钥权限 600 且被 Git 忽略。迁移机器需备份该文件；指纹密钥自身轮换仍需安排旧记录兼容窗口。
