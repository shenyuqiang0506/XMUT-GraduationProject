# M2 身份、目录与 Web 验收

日期：2026-10-11。对应 [08 的 M2](08-开发验收与部署.md)：数据库迁移、导入、登录、授权、Web 基础页。M2 已完成本机 dev 验证；预约/审批是 M3，移动端按用户要求暂缓，prod 仅准备配置。

## 实现范围

| 要求 | 实现与证据 |
| --- | --- |
| 数据库迁移 | identity_db：账号、三角色、角色关系、设备会话、已轮换刷新 hash、管理员并发保护、幂等与审计；booking_db：目录、审批组/成员、资源管理员、设施、设备、导入批次/错误、开放规则表、幂等与审计。两服务独立 Flyway V1 与分库账号 |
| 正式登录与会话 | BCrypt cost 12；RS256 访问令牌默认 15 分钟，issuer/audience/sub/sid/auth_version/时间校验；7 天设备会话，刷新只存 SHA-256，每次轮换；重用旧刷新令牌撤销整个会话 |
| 服务端授权 | 网关验签，业务服务再次验签并实时获取身份；数据库检查账号启停、身份版本、会话撤销/到期及当前角色；身份不可用返回 503；客户端 X-User-Id/X-Roles 被网关移除 |
| 账号管理 | SYSTEM_ADMIN 创建、分页、启停、改角色；乐观身份版本与幂等；变更撤销会话；事务防止删除最后一个有效系统管理员 |
| 管理范围 | 审批组成员与资源管理员由系统管理员配置，跨库通过身份服务校验有效管理角色；资源管理员只管理授权范围；学生只看到已开放且审批组有效的资源 |
| 资源目录 | VENUE/EQUIPMENT，字符串来源 ID，未知容量保持 null，位置/分类/设施/设备属性，来源 YES/NO/UNKNOWN 与平台生命周期分别保存；按校区/楼栋/类型/容量/分类/REAL-DEMO 分页筛选 |
| Excel/JSON 导入 | 实际文件行数、字段映射、逐行错误、明确来源与数据模式、受控原文件保存、SHA-256 核验、预览/确认幂等；按来源主键更新，不删除文件之外的资源；全部写入同事务 |
| Web 基础页 | Vue/TypeScript/Element Plus：登录、目录列表/详情/新增/编辑、审批组成员、资料导入、账号启停/角色；角色路由；访问/刷新令牌只留当前页面内存，deviceId 留本机；并发 401 共用一次刷新 |

导入仅支持 `RESOURCE_CATALOG`。学校占用/空闲区间导入、完整覆盖和开放规则接口需与 M3 可用性查询一并实现；开放规则表本次仅建立结构。目录 OPEN 返回时段可用性 UNKNOWN，其他状态返回 CLOSED，coverageStatus 恒为 UNKNOWN，不能据此宣称可预约。

## 实际验证

全部服务通过真实 dev Nacos 注册并由 Gateway 调用，MySQL 8.4 使用 InnoDB，Redis 保持真实连接。测试使用独立注册组与随机资料前缀，结束清理自身资料与临时进程；保留迁移和初始化管理员。

| 检查 | 结果 | 记录 |
| --- | --- | --- |
| 根 Maven 七模块 verify | 通过，原有 5 项基础测试 | 编译/测试适用于全部 Java 模块 |
| 正式身份 API | 通过，15 组 | [authentication.json](../verification/2026-10-11/m2/authentication.json) |
| 资源目录、导入与权限 | 通过，13 组；额外 1 组记录浏览器验收 | [catalog-import.json](../verification/2026-10-11/m2/catalog-import.json) |
| Web 类型检查与生产构建 | 通过 | `npm run build` |
| Web 实际浏览器 | 通过，3 场景，0 失败 | [web.json](../verification/2026-10-11/m2/web.json) |
| dev/prod 配置隔离 | 通过 | 独立 Docker 项目/卷/网络/端口/密码，JWT 密钥、issuer/audience、导入路径隔离，文件 600 且忽略 |
| M1 模拟模型调用链回归 | 通过，15 组 | [local-protocol-stub.json](../verification/2026-10-11/m1/local-protocol-stub.json) |
| Docker 基础集成回归 | 通过，4 项 | MySQL 回滚、Redis、RabbitMQ、Nacos；`verify-dev.sh` |

创建账号的幂等指纹先对初始密码做派生 HMAC，避免数据库中的普通快速摘要成为离线猜密码入口。派生密钥绑定身份私钥；轮换私钥时需协调未到期创建账号幂等请求的重试窗口。

身份覆盖登录/错误密码/伪造身份、JWT 错误签名算法与 claim、幂等创建、角色变更、停用、退出、刷新轮换/重用/并发及身份故障。额外把**临时身份进程**的 Redis 端口设为不可达：已登录会话仍查数据库，退出仍撤销；新登录因限流不可用返回 503，Docker Redis 未停机。

目录覆盖范围隔离、版本冲突、设备资产冲突回滚、JSON `totalResult=1132` 但实际 3 行、中文 XLSX/前导零/空容量、重复更新、编号冲突/缺名称/负容量/重复行、敏感列排除、原文件被修改、确认前授权移除及文件大小/格式限制。导入设备更新保留人工维护的 conditionStatus 与设施信息。

浏览器使用隔离 Chromium，连接真实 API：管理员登录/资源新增编辑/创建账号/导入确认/错误禁用确认/退出，学生路由与目录范围，资源管理员管理范围；人为同时返回两次 401，确认只进行一次真实刷新。测试不保存令牌、密码、视频或登录后的调试 trace。公开记录仅含摘要。

首次目录迁移发现 MySQL `row_number` 保留字；修正为引用列名，并确认失败时创建的目录表全为空后仅清理这些空表及失败记录，再成功应用。后续成功迁移禁止修改 V1；新增结构需 V2。

## 运行与凭据

按 [根 README](../../../README.md) 和 [部署说明](../../../deployment/README.md) 构建，在根目录执行：

```sh
python3 deployment/scripts/dev-workspace.py start
python3 deployment/scripts/dev-workspace.py status
python3 deployment/scripts/dev-workspace.py stop
```

页面 <http://127.0.0.1:5173>。初始化账号原始密码在本机 `deployment/secrets/dev/business-accounts.md`，Git 不保存此文件；数据库 password_hash 无法解密还原。生产没有 dev 管理员，首次管理员需另行完成受控初始化。

直接依赖固定版本：Vue 3.5.43、Vue Router 5.4.0、Pinia 4.0.3、Element Plus 2.14.7、Vite 8.3.4、Vue 插件 6.0.10、TypeScript 5.9.3、vue-tsc 3.3.13、Playwright 1.64.0。Node 26.10.0/npm 11.19.1 验证；npm 安装审计 0 漏洞。当前 Vue 检查工具与 TypeScript 7 不兼容，故固定 5.9.3；锁文件随源码提交。
