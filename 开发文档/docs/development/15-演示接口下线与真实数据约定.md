# 演示接口下线与真实数据约定

日期：2026-10-12。本次范围为演示接口退役和日常真实数据默认配置，不推进预约申请、审批等后续业务。

## 实现变更

- 删除身份、预约、AI 演示控制器及硬编码资源、演示 Feign 客户端、AI 演示工具与配置。
- 删除网关演示路由、共享演示 Basic 认证、`application-m1.properties` 和两份专用脚本；正式组件统一使用 `business` profile，不再引用阶段编号。
- 保留 AI 服务依赖、模型配置和身份接入骨架；当前没有正式 AI 查询接口。既有模型密钥保持本机私密配置，不写入 Git。
- 页面新增资源、资料导入、可用性查询、策略范围默认 REAL；未保存的策略参数留空，必须依据制度填写。
- 自动验收必须显式选择独立的测试资料模式；已有资料不批量改标，已执行的 Flyway 迁移不修改。
- 新回归报告按上海日期和业务用途归档，历史 M1 文档与证据保留并标注为已退役版本的记录。

## 数据约定

用户后续提供的数据集均按真实来源处理，导入使用 REAL。REAL/DEMO 描述数据来源性质，dev/prod 描述部署环境；本机 dev 可以处理真实数据，不因运行环境自动变成演示资料。

真实目录仅证明文件中的资源信息，不能推导未提供时段的完整占用或空闲状态。继续校验来源系统、字符串编号、采集时间、覆盖范围和数据有效期；缺失容量、规则或覆盖仍保持未知。真实预约制度需要明确依据，不采用演示参数。

自动化测试使用随机来源及测试账号，DEMO 标记继续用于隔离合成资料；真实模式隔离检查使用明确标注的临时测试样例，结束后清理。这些测试资料不属于用户提供的数据集。
