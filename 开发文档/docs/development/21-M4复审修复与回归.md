## 2. 登录来源与刷新契约

登录来源密钥与后台资格调用密钥分开，均为各环境独立 32 字节文件；登录密钥仅发给 gateway/identity，booking/notification/AI 不领取。网关签名头为 X-Login-Peer、X-Login-Time、X-Login-Nonce、X-Login-Signature，用途固定为 POST /auth/login，不赋予用户权限。防重放不可用时返回 503，来源和账号计数仍分别为每来源 30 次/60 秒、每账号 10 次/900 秒。共享同一 NAT 的客户端仍共享来源额度；这里解决的是网关转发把所有独立来源变成网关地址。尚未支持任意前置代理，两个服务禁用普通转发头对对端地址的改写。

新增 503 `REFRESH_NOT_EXECUTED` 只用于身份服务轮换前的查找故障，或网关确定没有下游实例/尚未建立连接。数据库提交失联、转发超时、响应丢失及格式错误不承诺尚未轮换：页面保留编辑内容，但进入 `refreshUncertain` 状态并提示用户保留内容后重新登录，不再次提交旧刷新令牌。真实 401/403 仍清理身份。此设计未新增令牌持久化、旧令牌宽限或刷新重放恢复机制。

## 3. 环境准备与运行

```sh
python3 deployment/scripts/prepare-messaging.py dev
python3 deployment/scripts/prepare-messaging.py prod
python3 deployment/scripts/prepare-idea.py
```

已为本机 dev/prod 准备独立 login-peer.key，权限 600，已有账户密码和密钥不轮换。私密 dev IDEA properties 已增加登录来源密钥路径，共享运行配置及端口保持原设置。已有进程需要重启后加载新代码及配置；prod 只准备配置，不启动服务。

```sh
./GraduationProject/mvnw -s .mvn/settings.xml -B -ntp package
cd web-admin
npm run build
npm run test:frontend
cd ..
python3 deployment/scripts/review-fixes-smoke.py
python3 deployment/scripts/auth-smoke.py
```

review-fixes-smoke 使用独立 18981–18983 端口、Nacos group 和 JWT audience，调用真实 dev MySQL/Redis；随机 DEMO 目录、账号、策略、申请、候补和导入文件在 finally 清理，恢复原 DEMO 生效策略。关闭自己的 Java 子进程，不暂停 Redis/RabbitMQ，不触碰 REAL 资料或 prod。auth-smoke 使用 8081–8083，运行前会拒绝已占用端口。
